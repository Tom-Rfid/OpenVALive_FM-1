# 01 — Overview

**OpenVALive FM-1** is a live-first firmware for the M-VAVE FM-1: four tracks with their own loops, CAPTURE, undo,
scenes and Morph, hold-to-play effects and a Creative Engine, on a virtual analog synth and an 808-style drum
machine.

| Repository | What | Licence |
|---|---|---|
| **OpenVALive_FM-1** (this one) | the FM-1 target (`targets/fm1`), site, installers, prebuilt files | MIT |
| [OpenVALive_CORE](https://github.com/Tom-Rfid/OpenVALive_CORE) | the synth, the Live Core and the app, in the `va/` submodule | MIT |
| [OpenVALive_SMK-37](https://github.com/Tom-Rfid/OpenVALive_SMK-37) | the same instrument on the SMK-37 Elite / Pro | GPL-3.0 |
